# UI/UX Specification

## Design principles
- Mobile-first
- Photography-focused visual design
- Fast path to booking
- Clear status text
- Color is supplementary, never the only status indicator
- Accessible contrast
- Large touch targets
- Minimal form fields

## Home
Hero -> Services -> Portfolio -> Packages -> Booking steps -> Reviews -> FAQ -> CTA

## Booking
Progress indicator:
1 Service
2 Date & time
3 Customer
4 Review
5 Payment
6 Confirmation

## Calendar labels
- Available: "เช้าว่าง / เย็นว่าง"
- Full: "เต็ม"
- Closed: "ปิดรับจอง"
- Past: "ไม่สามารถเลือก"

## Payment
- Large amount
- QR
- Account/merchant name
- Save QR
- Upload slip
- Pending verification state

## Admin
- KPI cards
- Revenue/booking charts
- Calendar
- Pending payment queue
- Upcoming bookings
- Customer search
- Filters

## Responsive
Mobile: single-column, sticky primary CTA where useful
Tablet: 2-column sections
Desktop: max-width content, sidebar admin
