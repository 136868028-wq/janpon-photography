# Admin Dashboard Specification

## KPI cards
- Today bookings
- This month bookings
- Confirmed
- Pending verification
- Completed
- Cancelled
- Deposits collected
- Outstanding balance
- Revenue

## Charts
1. Booking trend by day/week/month
2. Revenue trend
3. Service distribution
4. Booking source distribution
5. Funnel:
   visit -> service selected -> calendar viewed -> booking started -> payment started -> verified

## Operational widgets
- Today's schedule
- Upcoming 7 days
- Pending payment verification
- Expiring holds
- Recent cancellations
- Recent reviews

## Filters
- Date range
- Service
- Photographer
- Booking status
- Payment status
- Source/campaign

## Export
- CSV export for bookings
- CSV export for payments
- Customer list export subject to privacy rules
